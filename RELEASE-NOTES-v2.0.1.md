# Echo Music PC v2.0.1

I focused this update on a handful of specific playback and presentation fixes:

- Kept sidebar icons aligned as the navigation sidebar collapses.
- Added a subtle tint from the active theme to the track right-click menu.
- Smoothed the playlist artwork gradient so its color fades evenly.
- Added a keyboard-shortcut guide in Settings.
- Removed the separate Share Song button from the player strip and simplified the fullscreen **Back** label.
- Flushed queued output when playback is paused or a different track is selected, to prevent leftover audio from the previous selection from leaking through.
- Stabilized the Settings content width so it does not unexpectedly expand across the whole window.
