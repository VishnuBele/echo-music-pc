# Echo Music PC v2.0.5

**Released:** 26 October 2026

## What's new

- Home refresh replaces its recommendation snapshot and reshuffles Spotlight and quick picks.
- **Suggested for You** holds one selected pick across redraws and plays that exact track. With Echo Brain Autoplay enabled and idle playback, startup/Home refresh starts the fresh Home pick.
- Autoplay-generated radio recommendations can be refreshed alongside Home. The current track and manually queued items are preserved, and outdated background results are ignored after playback or queue changes.
- Update notices display the release publication date and format these notes as Markdown.

## Details

GitHub's release publication timestamp supplies the date shown by the updater. Recommendation results remain service-dependent; refreshing requests fresh data but cannot guarantee different recommendations.
